## 📌 Sobre o Projeto

O **ScreenMatch Quotes** é uma aplicação completa (Client-Server) desenvolvida para gerenciar e exibir citações de filmes e séries. 

Neste projeto, construí uma **API REST completa**, alimentando dinamicamente uma interface web interativa com dados estruturados, utilizando **Spring Boot no backend e JavaScript no frontend**[cite: 5]. O foco principal foi garantir uma comunicação fluida entre o backend e a interface visual, aplicando boas práticas de arquitetura e design de rotas.

## ⚙️ Funcionalidades

- **API RESTful:** Endpoints bem estruturados para o fornecimento de citações aleatórias.
- **Integração Backend/Frontend:** Consumo de dados via `fetch` API no JavaScript.
- **Interface Interativa:** Frontend dinâmico (HTML/CSS/JS) que exibe as informações consumidas diretamente do servidor.
- **Modelagem de Dados:** Estruturação cuidadosa das entidades (Quotes) no backend.

**Frontend:**
